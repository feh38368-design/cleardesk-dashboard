# ClearDesk — Business Dashboard Concept

ClearDesk is a responsive front-end dashboard concept for a portfolio. It demonstrates a modern SaaS-style workspace with overview metrics, a revenue chart, project progress, tasks, client directory, analytics, and preferences.

## Run locally

Open `index.html` in a modern browser. The project uses plain HTML, CSS, and JavaScript; no build step is required. Google Fonts are loaded online, with system fonts used as fallback.

## Deploy with GitHub and Vercel

1. Extract `ClearDesk-Dashboard-Concept.zip` on your device.
2. Create a new GitHub repository, for example `cleardesk-dashboard`.
3. Upload `index.html`, the `assets` folder, and this `README.md` to the repository root.
4. In Vercel, import the repository. The project is a static site; no framework or build command is required. If prompted, leave the build command empty and use `./` as the output directory.
5. Deploy and open the live URL to test on mobile and desktop.

## Features

- Responsive desktop and mobile layout with collapsible mobile navigation
- Overview dashboard with sample metric cards and SVG revenue chart
- Projects, tasks, clients, analytics, and settings views
- Add and complete tasks in the current browser session
- Export demo task list to CSV
- Search sample projects, tasks, and clients
- No external API, account, database, or payment connection

## Important demo note

All displayed business metrics, clients, projects, and activity are fictional sample data for UI demonstration only. The app does not process real payments or store data in a backend. Tasks added during a session are kept in browser memory and reset when the page is reloaded.
